# Frontend Rules

- Inspect existing UI components before creating new ones.
- Reuse the project's shared components and design system.
- Follow established props, variants, styling, and composition patterns.
- Reuse existing API clients, hooks, and service functions.
- Follow existing state management, data fetching, and validation conventions.
- Preserve responsive behavior and accessibility.
- Avoid duplicate components, raw API calls that bypass shared clients, and unnecessary dependencies.
